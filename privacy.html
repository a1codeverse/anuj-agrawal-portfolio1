PRIVACY PORTFOLIO WEBSITE

Privacy information.

This is a static portfolio website and front-end demo. This page describes how the current version handles contact actions and the sample project enquiry form.

Project enquiry form

The current form does not send information to or store it on a website server. When submitted, it prepares a message and opens a WhatsApp chat link so you can review the information before choosing whether to send it. The information you send will then be processed by WhatsApp according to its own policies.

AI assistant

The included assistant is a local scripted preview for portfolio questions; it does not connect to an external AI service or store the conversation on a server. A production AI integration would need a separate privacy review and secure backend.

External links and certificates

The site links to WhatsApp, email, LinkedIn and original certificate PDFs. Those services and documents may be governed by their own privacy terms. Certificate previews are based on files supplied for this portfolio.

Analytics and cookies

The current code does not intentionally set analytics or advertising cookies. Hosting providers may still process basic technical request data depending on the hosting service and its configuration.
